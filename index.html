How to Use This App

1️⃣ Choose Your Mode

When you open the app, you see two mode options at the top:

  • ERP MODE — Use this when you have an ERPNext Vendor Payment Report or Expense Claim Report. The app reads the columns, maps them to Kotak format, checks every row, and lets you edit before downloading.
  • GENERIC MODE — Use this when you already have a pre-formatted Kotak Excel file (like the one made by the old KMBL Excel tool). It just converts the columns to a tilde-separated TXT file. No field mapping and no checks.

2️⃣ Select Fund Type

Click Non-FCRA for regular vendor payments, or FCRA for foreign contribution payments.

Each fund type has its own Debit A/C: Non-FCRA 0711160987 and FCRA 4812763856. Switching the fund type switches the account automatically, so the two are never mixed up. Always check the account in the confirmation box before downloading.

3️⃣ Upload Your File

Drag and drop your Excel file onto the upload area, or click to browse. You can upload:

  • Vendor Payment Report (.xlsx) — detected by sheet name "Vendor Invoice"
  • Expense Claim Report (.xlsx) — detected by sheet name "Expense Claim" or column "Employee Name"
  • Multiple files — select more than one file at once
If you already have data loaded and upload another file, a popup asks:
+ Add to existing = append new rows below current ones
Replace all = clear everything and load only the new file
If you add the same file twice, the app warns you and flags the repeated payments as possible duplicates.

The Filter: Workflow State setting ("To Pay only" or "All rows") applies to the next file you upload.

4️⃣ Set the Payment Date *

This is the most important field. The date defaults to today, and every row uses it unless you edit that row's date.

BLOCKS DOWNLOAD A past date is rejected by Kotak Bank with "Backdated Transaction Date". The app shows a warning and will not let you download until the date is today or later.

5️⃣ Fill the Debit Account *

The Debit A/C is filled in for you from the fund type — Non-FCRA 0711160987, FCRA 4812763856 — and goes into every row. If you change it, your value is remembered for that fund type; Restore default settings brings back these accounts.

If you edit one row's Debit A/C in the table, that row keeps your value even if you change the configuration later. Download stays disabled while the Debit A/C is empty.

6️⃣ CC Emails

Each CC email is shown as a chip. The count is next to the label.

  • Add — type an address and press Enter or comma. You can also paste several addresses at once.
  • Remove — click the × on a chip.
  • A red chip is not a valid address (for example name@iima,ac.in). Fix it before downloading.
  • For each row, the supplier email (col V) and creator email (col AF) are added automatically. Hover the ✉ badge on a row to see its full email list.

7️⃣ Review and Edit the Rows

After upload, all rows appear in an editable table. Click any cell to change it — Beneficiary Name, IFSC, Account No, Amount, Date, Debit A/C, Enrichments.

  • NEFT and IFT — Each row has its own payment type. If the beneficiary bank is Kotak (IFSC starts with KKBK), it auto-selects IFT and uses IFSC KKBK0000958. The IFSC cell is locked on IFT rows; switch the row to NEFT to edit it.
  • Edited cells turn yellow. Typing the original value back clears the highlight.
  • Your edits flow everywhere: the bank files, the totals, the stats and the approval email always show the same amounts.
  • Click ✕ at the end of a row to remove that payment. ↶ Undo remove brings back the last removed row.
  • Each row shows a VEN or EXP badge for Vendor or Expense Claim rows.

8️⃣ Checks Before Download

The app checks every row as you work. The panel above the table lists what it found; click any item to jump to the cell.

Error
Download is disabled until fixed: empty Debit A/C, past date, invalid CC email, empty name, missing or invalid IFSC (must be 11 characters like HDFC0001234), empty account number, amount not a number or not more than 0, a row date that is not DD/MM/YYYY.
Warning
You can still download, after confirming: possible duplicate payment (same account, amount and invoice no), account number with letters or unusual length, amount with more than 2 decimals, invalid supplier/creator email.
Problem cells are coloured red (error) or amber (warning). Hover a cell to see why. When everything passes, the panel turns green.

9️⃣ Download Payment Files

Three download buttons at the bottom:

Kotak XLS
49-column Excel file for the Kotak Bank portal.
Kotak TXT
Tilde-separated text file (~). Same data, alternate format. This is what the bank actually processes.
Download Both
Downloads XLS first, then TXT half a second later.
Before anything downloads, a confirmation box shows the fund type, number of payments, exact total, Debit A/C, payment date and NEFT/IFT split, plus any warnings. Check it, then click Confirm & Download.

🔟 Email Approval Template

After uploading, an approval email is auto-generated with a table of all payments. Use it to get payment approval from management.

  • To and Signature name are editable at the top of the panel and are remembered.
  • ✉ Draft in Gmail — opens a new Gmail draft with the To and Cc addresses and the subject filled in, and copies the formatted email (with the payment table) to your clipboard. Gmail cannot receive a table through a link, so you paste it: in the draft, triple-click the line "Triple-click this line…" and press Ctrl+V (⌘V on Mac). The full email with the table replaces that line. Attach the Excel if needed, then send. Gmail keeps it in Drafts until you send it.
  • The steps also appear under the buttons, with Copy table again in case you copied something else in between.
  • Sign-off in Gmail draft — leave on "None" if your Gmail already adds your signature (so it isn't repeated); choose "Add" otherwise.
  • By default the draft goes To Amitkumar (amitkj@iima.ac.in), with Roshan, Purushottam, Hetal, Neeraj, Sanea and Vipin (vipinn@iima.ac.in) in Cc. Change Gmail draft: To and Cc if needed — your changes are remembered. If you are signed in to several Google accounts, put the one to send from in Gmail account.
  • If the browser blocks the Gmail window, allow pop-ups for this page and click again.
  • Copy Email — copies subject + body to the clipboard. Paste into Outlook or Gmail.
  • Download Email as Excel — downloads the payment table as a .xlsx file to attach to the approval email.
  • Set the Letter / Batch No (e.g. 01, 02) in configuration — it goes into the email subject line.
  • Neat formatting: in the approval email (preview, Gmail draft, Copy Email and the Email Excel), vendor names are shown in Title Case ("ACME TECHNOLOGIES PVT LTD" → "Acme Technologies Pvt Ltd") and the purpose as a sentence ("CONSULTING FEES FOR SEPTEMBER" → "Consulting fees for September"), with the purpose column justified. Short forms like GST, HDFC, LLP and IIMA stay in capitals. Text that already mixes capitals and small letters is kept exactly as written. The bank files are not changed.
  • If a name still doesn't look right (for example an acronym the app doesn't know, like "ABC"), edit the Beneficiary Name in the table using mixed case (e.g. "ABC Consultants") and the email uses it exactly.

⚠️ Things That Cause Bank Rejection

  • Backdated Date — Payment date in the past. The app blocks download until fixed.
  • Special Characters — Only A-Z, 0-9, space, / and - are allowed in text fields. The app auto-strips everything else, including in cells you edit.
  • Wrong IFSC — IFT rows must use KKBK0000958 (handled automatically). NEFT IFSCs are checked for the correct 11-character format.
  • Empty Debit A/C — The app blocks download until it is filled.
  • Leading zeros — Bank accounts starting with 0 (e.g. 00123456) must keep the zeros. The app preserves them.
