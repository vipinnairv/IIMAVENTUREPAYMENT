# IIMAVENTUREPAYMENT

Kotak Payment Letter Conversion — a single-page browser tool that converts an
ERPNext Vendor Payment / Expense Claim report into Kotak Bank payment files
(XLS and TXT), with pre-upload checks, a maker/checker approval email, and a
local payment-review memory.

Open `index.html` in a browser. No install or server is needed.
